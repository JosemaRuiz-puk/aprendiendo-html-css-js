📰 Pulso Manchego

¿Qué es esto?

Pulso Manchego es una pequeña aplicación de noticias que hice mientras estudiaba Desarrollo de Interfaces en DAM.

La idea era bastante sencilla: tener un sitio donde consultar noticias de Castilla-La Mancha, ver también noticias del resto de España y poder buscar cualquier tema que me interesase.

Está hecha con Flutter y Dart y utiliza NewsAPI para obtener las noticias.

¿De dónde salió?

Pulso Manchego nació como una práctica del módulo de Desarrollo de Interfaces del ciclo de Desarrollo de Aplicaciones Multiplataforma.

En aquel momento estábamos trabajando con Flutter y una de las cosas interesantes era comprobar cómo un mismo proyecto podía funcionar como aplicación y también desde un navegador.

Y de ahí salió Pulso Manchego.

Y sí, aquí hubo mucha IA

Esta práctica tiene una particularidad: el código original fue generado íntegramente con ayuda de inteligencia artificial.

Yo fui decidiendo qué quería que hiciera la aplicación, qué apartados debía tener, qué había que cambiar y cómo quería que funcionase. Después tocaba probar, detectar fallos y seguir haciendo cambios hasta conseguir que todo funcionase.

Así que también fue una forma de experimentar con el uso de la inteligencia artificial durante el desarrollo de una aplicación.

¿Qué hace?

  • Muestra noticias relacionadas con Castilla-La Mancha.
  • Muestra noticias del resto de España.
  • Permite buscar noticias sobre cualquier tema.
  • Muestra el titular, la imagen, la fuente y la fecha de publicación.
  • Puede ejecutarse como aplicación Flutter y también directamente desde la web.

Y casi acaba en el cementerio de proyectos...

Tiempo después borré por error la carpeta donde tenía guardado el proyecto y durante un rato pensé que Pulso Manchego había desaparecido para siempre.

Por suerte, Visual Studio Code conservaba versiones de los archivos en su historial local. A partir de ahí pude recuperar el código, reconstruir de nuevo el proyecto Flutter y comprobar que la aplicación seguía funcionando.

Ya puestos, decidí darle una segunda vida y traerla hasta esta web para que no se quedase simplemente olvidada en una carpeta del ordenador.

Una pequeña mejora por el camino

La versión original llevaba la clave de acceso a NewsAPI dentro del propio código de la aplicación.

Eso no era una buena idea al publicarla en Internet, porque esa clave podría quedar accesible desde el navegador.

Ahora Pulso Manchego hace las consultas a través de un pequeño servicio PHP alojado en mi propio servidor. La aplicación pide las noticias al servidor y es el servidor quien se comunica con NewsAPI, manteniendo la clave fuera de la aplicación pública.

¿Con qué está hecho?

  • Flutter
  • Dart
  • NewsAPI
  • PHP
  • HTML y CSS
